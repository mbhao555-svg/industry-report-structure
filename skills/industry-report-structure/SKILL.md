# 行业报告结构改造器（投资版）

**把"信息很全但读不出结论"的行业报告，改造成能回答"投哪一段"的投资分析报告。**

> **本技能有两只手**：
> - **左手——投资判断**：补齐并**做出**阶段判定／环节级利润分布／出清机制，最后落到投资含义矩阵。**这些判据是从 `industry-deep-research` 移植进来的完整版本，本技能可独立完成，不需要去调另一个技能。**
> - **右手——结构呈现**：骨架诊断、并列项表格化、集群对照表、标题与内容一致性核对。

| 技能 | 负责 | 什么时候用 |
|---|---|---|
| `industry-lifecycle-analyzer` | **只判阶段**（独立工具） | 问题只是"这行业什么阶段" |
| `industry-deep-research` | **从零检索取证 + 成稿** | 手上没有报告，要从头做 |
| **本技能** | **改造已有报告＝补投资判断 + 重排结构** | 报告已存在，要"改成能投的" |

**分工的实际含义**：

| 情形 | 做法 |
|---|---|
| 报告已存在，缺投资判断 | **本技能做**——判据已内置，直接补 |

| 手上什么都没有 | 用 `industry-deep-research` |

## 二、九节信息骨架

**定位**：信息密度优先的产业全景骨架。比常见七节更细，代价是篇幅更长。

| # | 节 | 必须回答 | 常见缺失 |
|---|---|---|---|
| 一 | **定义与涵盖范围** | 官方统计口径落在哪几个分类代码下？工艺边界？主流品类？ | 不交代**分类代码**与**标准切分点** |
| 二 | **产业链构成与区域分布** | 上/中/下游是什么？产能按什么逻辑分布？几个集群？ | 不写**分布导向**（原料地／口岸／冷链节点） |
| 三 | **行业现状** | 大盘、产量、加工转化率、进出口、政策框架 | 有数字无判断——**缺阶段判定** |
| 四 | **龙头企业** | 两条主线？关键经营数据？ | **只给营收，不给毛利率** |
| 五 | **国际地位** | 占全球多少？差距在哪？壁垒？ | 只讲份额不讲**差距性质** |
| 六 | **发展趋势** | 沿哪几条主线升级？ | 趋势与数据脱节，变成愿景 |
| 七 | **机遇／挑战／策略** | 各有哪些？策略是什么？ | **策略是企业该怎么办，不是投哪一段** |
| 八 | **产业聚集区案例** | 有哪些集群、各自特征？ | **写成 N 篇小通告，无法横向比较** |
| 九 | **总结与展望** | 核心结论 + 3–5 年展望 | 与正文重复 |

**改造为投资版时的骨架调整**：第三节增阶段判定、第四节增环节级利润分布与出清机制、第七节策略改为投资含义映射。**其余节保留。**

## 三、投资判断三件套（本技能的核心能力）

**判据说明**：以下三节是**完整判据**，可独立执行。**不再需要查另一个技能。**

### 维度 A：行业阶段判定

#### A.1 判断顺序（按序执行，命中即停）

```
① 需求是否被行政命令禁止？          → 政策终止（结束）
② 是否被更优技术整体替代？          → 技术终止
   ⚠️ 须查两步，缺一不可：
     ① 是否【曾】被替代？（看历史有无长期萎缩期）
     ② 需求【现在是否仍单向转移】？（看近 1–2 年）
        若原品类台数与金额【双增】→ 需求回流 → 【不判技术终止】
   ⚠️ 先确定被替代的是哪个【品类边界】：
     蓝牙音箱 +3.9% 而智能音箱 −50.5% → 被替代的是"带语音助手的音箱"，
     不是"音箱"。品类内某一层失效 ≠ 整个品类被技术终止
③ 是否仍在下降？                    → 衰退期
④ 是否已止跌且剩余玩家普遍恢复盈利？ → 衰退后回稳
   ⚠️ 须同时满足"量连续 2 年不下滑"+"剩余玩家普遍恢复盈利"。
      仅降幅收窄不算，仍判衰退期
⑤ 其余                              → 按五指标 + 渗透率校准判四阶段
```

**⚠️ 顺序不可颠倒。** 若颠倒，特殊标签行业会在五指标上投出"衰退期"（如 K12 机构数 −96%），再被"以规模增速为终审"确认，**从而把"政策终止"误判成"衰退期"**——两者**决策含义相反**（一个看政策是否重开，一个看需求是否见底）。

#### A.2 五指标投票

| 指标 | 投"成熟期"的信号 |
|---|---|
| 一、增长率 | 增速落入 0–10%，且多年走平 |
| 二、竞争者数量 | 多、不减少、集中度不再提升 |
| 三、进入壁垒 | 低、无强制资质 |
| 四、产品标准化 | 高度同质、比价为主 |
| 五、利润率 | 稳定但不高，或持续被动下行 |

**三个易错点（必须执行）**

| # | 易错点 | 正确处理 |
|---|---|---|
| ① | **标准类事件的性质** | 问"该标准发布**之前**，品类是否已存在并规模化？"——之前**不存在** → **品类定义标准** → 读作成长期；之前**已存在** → **运营服务标准** → 读作成熟期（是规范化，不是品类诞生） |
| ② | **利润率的方向** | 同样的"低利润"含义相反：**低利润 + 高增速 + 玩家增多** → 导入/成长早期价格战；**低利润 + 低增速 + 玩家退出** → 衰退期；**高利润 + 高增速** → 成长期黄金窗口；**高利润 + 低增速 + 高集中度** → 成熟期寡头 |
| ③ | **产品标准化对服务业判别力弱** | 服务流程天然可比（"扫码+计时"必然"高度标准化"），**只能作辅助，不得单独决定阶段**，须以增长率与渗透率为准 |

**非实物行业的指标替换**（替换后再判，**不得编造固定阈值**）

| 业态 | 替换/补充指标 |
|---|---|
| 服务／教育／医疗 | 续费率、客单价、人效、满班率或床位使用率、退费率 |
| SaaS／订阅 | GRR/NRR、CAC、LTV、流失率、ARPU |
| 平台／双边市场 | 两侧用户数及比例、GMV、take rate、网络密度、**单侧留存（两侧分开看）** |
| 项目制／工程 | 在手订单、订单转化周期、应收账款周转、履约进度确认 |
| 零售／连锁 | **同店增速（非单店）**、坪效、库存周转、闭店率 |
| 金融／高杠杆 | 不良率、资本充足率、拨备覆盖率、净息差 |
| 重资产／基建 | 产能利用率、折旧占营收比、资本开支/营收比 |
| 资源／大宗 | 价格周期位置、库存周期、边际成本曲线位置 |

> ⚠️ **替代指标的正确用法是两步映射**：①先映射回它替代的是哪个原始指标（增长率/竞争者/壁垒/标准化/利润）；②再用"**相对水平**（相对盈亏平衡点或历史常态是高/持平/低）**+ 趋势方向**（升/平/降）"定阶段内**位置**。行业基准取不到时，用**头部企业**或**该行业 3 年前的自身值**作参照；都取不到时**只报趋势方向，不报水平判断**。

#### A.3 渗透率校准（不投票，只设上界）

| 渗透率 | S 曲线位置 | 校准作用 |
|---|---|---|
| **< 5%** | 导入期 | 上界封在**成长期**，不得判成熟期/衰退期 |
| **5%–15%** | 导入期末／成长期最早期 | 上界封在**成长期** |
| **15%–20%** | **临界点**（越过即进入快速提升期） | 上界封在**成长期**（未越线时不得判成熟期） |
| **20%–35%** | 成长期（快速渗透段） | 不设硬上界；提示成熟期需强证据 |
| **35%–40%** | **临界点**（越过即增速开始放缓） | 提示进入成长期后段 |
| **40%–60%** | 成长期后段 → 成熟期 | 允许判成熟期 |
| **> 60%** | 成熟期（存量博弈）**← 须做深度校验** | **下界抬到成熟期**，不得判导入期 |

**两个临界点（15–20%、35–40%）必须显式写"处于临界点"并给出越过/未越过的依据，不得二选一。**

**两条硬规则（不可绕过）**

| 硬规则 | 执行 |
|---|---|
| **渗透率 < 20% → 不得判成熟期或衰退期** | 若五指标投出成熟期/衰退期，**改写为"成长期"**（或导入期），并写明冲突点 |
| **渗透率 > 60% → 不得判导入期** | 若五指标投出导入期，**改写为"成熟期"**，写明冲突点。⚠️ 实践几乎不出现，出现时**优先怀疑口径错误** |

**冲突点必须写清三件事**：① 五指标投出什么、依据哪几条 ② 渗透率读数、属哪档、触发哪条硬规则 ③ 修正后结论与理由。**不得隐去冲突。**

**前置检查**：本行业有"渗透率"这个概念吗？**没有就用替代指标**（3.7 条精神：映射 + 相对水平 + 趋势方向）。**口径即结论**——换分母就是换问题；多口径时**每个口径各自定阶段，不得平均**。

#### A.4 指标共线检查（投标前必做）

**共线指标只算一票。** 把共线指标当独立证据，会系统性高估置信度。

| 共线组合 | 为什么是同一份信息 | 处理 |
|---|---|---|
| **集中度高 ↔ 进入壁垒高** | 配额/牌照行业里，高壁垒正是"企业数少"的原因 | 问"低企业数是因为**壁垒挡住新玩家**，还是**出清后自然集中**？"前者同源，**不得两票** |
| **毛利率高 ↔ 定价权强** | 高毛利可能是周期高点、单笔订单或会计口径 | 定价权须由**客户集中度、切换成本、认证周期**独立支撑 |
| **环节毛利率高 ↔ 该环节价值高** | 同一份财报分部数据的两种表述 | 价值判断须另有依据（资本回报率、现金流、再投资需求） |
| **行业增速高 ↔ 该环节增速高** | 若该环节收入占比极高，两者基本是同一个数 | 需给出该环节**独立于行业**的驱动因素 |
| **生命周期阶段 ↔ 产业链结构** | 常源自同一批数据、同一批来源 | **不得把"阶段与结构互相印证"当作双重证据** |

**判定方法（两问）**：① **问因果**——A 高是不是 B 高的原因？② **问数据源**——是否来自同一份原始数据？

**执行**：注明同源项；**同源项不得用于提高置信度**——去掉同源项后只剩 1 个支撑的结论，**按"单源"处理并标注待核实**。

#### A.5 判据冲突裁决顺序

**按序裁决，前一条能解决就不进入下一条。**

| 优先级 | 判据 | 说明 |
|---|---|---|
| **终审** | **规模增速**（增长率指标） | 最直接、最难操纵 |
| **次审** | **渗透率区间** | 设定上界 |
| **仅参考** | **定性判据**（进入壁垒、标准化、标准发布等） | **只在缺增速数据时才能作为主要依据** |

**裁决记录四项必写**：① 冲突是什么 ② 适用哪一条 ③ 裁决结果 ④ **被否决方及理由**。

#### A.6 结构分化（每份必查）

**总量会掩盖结构。** 给出任何"行业整体低增长/衰退"的判断时，**必须同时检查**：① 是否存在增速 ≥ 行业整体 **3 倍**的细分 ② 其占比是否足以改变整体判断 ③ 是否构成"第二曲线"。**反向**：有无被整体增长掩盖的萎缩细分。

#### A.7 政策性扰动：负增长不等于衰退

政策刺激类行业**必做**。区分三类负增长：

| 类型 | 特征 | 读法 |
|---|---|---|
| **刺激退坡** | 与补贴/政策周期同步 | **读数失真**，不算阶段转换 |
| **需求透支** | 政策期内集中释放，随后回落 | 需判断是否已回落到趋势线 |
| **真实萎缩** | 与政策周期无对应，且有可识别替代品 | **按衰退细分处理** |

#### A.8 阶段标签总表（七个）与置信度

| 标签 | 定义 | 该观察什么 |
|---|---|---|
| **导入期／成长期／成熟期／衰退期** | 标准四阶段 | 见 A.2 五指标 |
| **政策终止** | 被行政命令终结——**需求仍在，但不得满足** | **政策是否重新开放** |
| **技术终止** | 被更优技术整体替代——**需求已单向转移且未见回流** | **是否有替代技术让它复活**；并观察需求是否回流 |
| **衰退后回稳** | 深度下滑后止跌，稳定在新均衡 | **新均衡能否维持** |

**三个特殊标签均不得与"衰退期"混用。**

**置信度合成**：五指标投票 + 渗透率校准**两套判断各自给置信度，合成时取较低者**；共线检查后**同源项不计入**。

### 维度 B：环节级利润分布

#### B.1 为什么企业级数据不够

**企业级 ≠ 环节级。** 只给龙头企业营收、不给毛利率，**答不出"钱在哪一段"**——营收大可能是低毛利走量。

| 常见错误 | 后果 |
|---|---|
| 只给企业营收、不给毛利率 | 无法判断哪一段有超额利润 |
| 用某企业整体毛利率代表它所在环节 | 企业常跨环节，整体毛利率是**混合值** |
| 企业跨业务时直接比较利润率 | 口径不可比（制造与品牌混算） |

#### B.2 取数方法：F10 分部接口（可直接执行）

```
https://emweb.securities.eastmoney.com/PC_HSF10/BusinessAnalysis/PageAjax?code={市场}{代码}
```

`code` 用 `SH`/`SZ`/`BJ` + 6 位代码。**无需登录、无需 key，一次返回该公司全部历史报告期的分部数据。**

| 顶层字段 | 内容 |
|---|---|
| `zygcfx` | **主营构成分析**——分产品/分地区的收入、成本、毛利、**毛利率**（主力数据） |
| `zyfw` | 主营范围 |
| `jyps` | 经营评述 |

**`zygcfx` 关键列**

| 列 | 含义 | 注意 |
|---|---|---|
| `REPORT_DATE` | 报告期 | 一次返回多年，**必须按报告期筛最新一期** |
| `MAINOP_TYPE` | 分类维度 | 1=按行业 2=按产品 3=按地区 |
| `ITEM_NAME` | 分部名称 | 含"其中:"的是细分项，**不要与父项重复计算** |
| `MAIN_BUSINESS_INCOME` | 分部收入 | 元 |
| **`GROSS_RPOFIT_RATIO`** | **分部毛利率** | ⚠️ ① 接口把 PROFIT 拼成 **RPOFIT**，写成 `GROSS_PROFIT_RATIO` 取不到值 ② 值是**小数比率**，0.15011 = 15.01% |
| `MBI_RATIO` | 收入占比 | 小数比率 |

> 🔴 **头号陷阱：跨维度相加会静默放大营收。** `MAINOP_TYPE` 的多个维度**各自都等于总营收**（按产品之和 = 按地区之和 = 总营收）。**跨维度相加会让营收膨胀 2–3 倍。** 取数时必须**只取单一维度**，并在表头写明取的是哪个维度。

**港股与海外上市主体**（如安德利果汁 02218.HK）**不在本接口范围**，需另行取证；**不得用同集团 A 股主体代替**。

#### B.3 输出格式

至少给出四列：

| 环节／分部 | 毛利率 | 收入占比 | 证据来源 | **样本量** |
|---|---|---|---|---|

**每个关键环节还应标注**（产业链拆解字段）：核心产品、关键投入、技术路线、代表企业（**必须有来源**）、主要客户与集中度、价值流向、认证与验证周期、供需格局、议价能力（强/中/弱 + 依据）、替代风险、**证据状态**（已核实/待核实/冲突）。

#### B.4 读数的三条纪律

1. **同一主体内跨业务比较会误导**：宏辉果蔬"药品销售 74.06%"与"水果 11.61%"**属不同业务口径**，**不得**用来论证"水果供应链可捕获 74% 毛利"。
2. **同一主体内跨环节对比才是最干净的证据**：同一家公司、同一报告期、同一会计政策下的环节差异——这是环节级证据强度最高的一类。
3. **样本量必须写出来**：单主体分部口径 = 样本量 1，结论强度**按"单源"处理并标注待核实**。

### 维度 C：出清机制逐环节

#### C.1 五问与三档

**"出清"指弱者退出、份额向头部集中。有出清机制的行业，低毛利是暂时的；没有的，低毛利是永久的。**

| # | 机制 | 判别信号 | 缺它则 |
|---|---|---|---|
| 1 | **并购整合** | 近 3 年是否发生并购？头部是否在收购中小玩家？ | 想整合但整合不了 |
| 2 | **标准与等级** | 消费端是否有被广泛认可的质量/等级标准？国标是否落地执行？ | **整合缺乏抓手**——无法区分优劣就无法溢价，也无法集中 |
| 3 | **监管门槛抬升** | 准入、合规成本是否在提高（新国标、环保、资质）？ | 新玩家持续涌入 |
| 4 | **渠道集中** | 下游渠道是否在集中（连锁化、平台化）？能否倒逼上游集中？ | 上游永远面对碎片化买方 |
| 5 | **规模经济显著** | 头部单位成本是否显著低于中小玩家（**差 ≥10%**）？ | 规模不产生优势，大者不能胜小者 |

| 命中数 | 判定 | 结构含义 | 投资动作 |
|---|---|---|---|
| **≥3 条** | **有出清机制** | 低毛利是阶段性的，格局会收敛 | **"剩者为王"**——投份额领先者与并购整合者，而非行业景气 |
| **1–2 条** | **出清缓慢** | 需要长周期等待，整合路径不清晰 | **"效率领先者"**——只投单位成本/周转显著优于同业的（差 ≥10%），**不投"行业反转"** |
| **0 条** | 🔴 **碎片化陷阱** | **长期低水平均衡** | **明确规避，或只投"绕开该环节"的位置** |

#### C.2 碎片化陷阱：独立形态，不得与衰退期混用

| | 成长期的高低度分散 | **碎片化陷阱** | | 衰退期 |
|---|---|---|---|---|
| 企业数量 | 快速增加 | 多，但**不减少也不快速增加** | 持续退出 |
| 集中度 | 低 | 低，且**无提升迹象** | 提升（弱者死了） |
| **规模增速** | **> 20%** | **已落入 0–10%** | 持续收缩 |
| 并购整合 | 罕见 | 罕见（**想整合但整合不了**） | 常见 |
| 成因 | 市场快速扩容 | **缺乏消费端统一标准** | 需求消失 |
| **决策含义** | 抢份额 | **观察出清机制是否出现** | 观察**需求是否见底** |

**两种常见误判及其代价**

| 误判 | 为什么错 |
|---|---|
| 按**成长期逻辑**（抢份额、烧钱换增长） | ❌ 格局不会收敛，**烧掉的钱换不来份额** |
| 按**衰退期逻辑**（等出清后抄底） | ❌ **没有出清机制，等不到那一天** |
| ✅ **正确做法** | ① 明确标注"碎片化陷阱" ② 结论落到"**绕开该环节**" ③ **列出"陷阱解除的前置条件"**（哪条出清机制出现了才算解除） |

#### C.3 🔴 出清判定必须落到环节，不得给行业统一判定

**同一行业内，不同环节的出清机制可以完全不同。**

| 环节类型 | 常见命中 | 典型判定 |
|---|---|---|
| 品牌／品种／技术端 | 标准 ✅ 规模经济 ✅ 监管 ⚠️ | **有出清机制** → 可投（剩者为王） |
| 基础设施／冷链／网络端 | 监管 ✅ 并购 ✅ 规模经济 ✅ | **有出清机制** → 可投（但常是"成本改善"而非定价权） |
| 流通／分销／零售端 | 标准 ❌ 规模经济 ❌ | **碎片化陷阱** → 🔴 规避 |

> **不得给行业一个统一的出清判定**——那会掩盖"两端可投、中间不可投"的真实结构。**出清判定必须与环节级利润分布并列输出。**

## 四、投资含义矩阵（判断的落点）

### 4.1 阶段 × 出清机制（12 格）

| 阶段 ↓ / 出清 → | **有出清机制**（≥3） | **出清缓慢**（1–2） | **碎片化陷阱**（0） |
|---|---|---|---|
| **导入期** | ⚠️ **极早期**：只投"卖铲人"（设备/材料/工具链），不投终端。**标准化是买入前提** | ⚠️ 同左但更严——只投有明确付费方的一环 | 🔴 **不投**：技术未定 + 无整合路径 = 双重不确定 |
| **成长期** | ✅ **首选**：投份额领先者。**黄金窗口** | ⚠️ **可投但挑环节**：只投单位成本/周转显著优于同业的（差 ≥10%） | 🔴 **陷阱高发区**——高增速会掩盖"格局永不收敛"。**只投"绕开该环节"的位置** |
| **成熟期** | ✅ **可投**：投整合者与被整合标的。**现金流与份额比增长重要** | ⚠️ **效率游戏**：只投成本领先者，**不投"行业反转"叙事** | 🔴 **最差组合**：低增长 + 无出清 = **长期低水平均衡**。**明确规避** |
| **衰退期** | ⚠️ **尾部出清**：投能活到最后的龙头，观察需求是否见底。实际落点为"**剩者为王 + 类债现金流**"——逻辑是**份额提升与分红，而非景气反转** | ⚠️ **谨慎**：出清慢意味着痛苦期更长 | 🔴 **不投**：既无增长也无出清 |
| **衰退后回稳** | ✅ **可投**：新均衡已被验证，投**格局与新均衡的维持能力** | ⚠️ 需确认新均衡不是暂时的 | 🔴 不投 |

### 4.2 三个特殊标签：不进矩阵，另按驱动力判

| 标签 | 判断依据 | 投资含义 |
|---|---|---|
| **政策终止** | 观察**政策是否重新开放**，不是需求是否见底 | 投"政策重开"的期权价值；**不得按衰退期抄底逻辑操作** |
| **技术终止** | 观察**是否有替代技术让它复活** | 一般规避；若存在复活路径，那是技术期权而非行业投资 |
| **衰退后回稳** | 须同时满足"量连续 2 年不下滑"+"剩余玩家普遍恢复盈利" | 可投**格局**（剩者），不可投**成长** |

### 4.3 矩阵使用纪律

1. **先定环节，再定阶段与出清**——同一行业不同环节可落在不同格
2. **"阶段 ≠ 景气"**：同判成熟期，"有出清"可投、"碎片化陷阱"须规避，**决策含义相反**
3. **空集要写"未压中"，不写"不可达"**："不可达"需要验证，不能靠推断
4. **只给阶段标签不给投资含义，等于没做判断**

## 五、可表格化的并列项清单

**判据**：凡"**同一维度下并列 N 个对象、每个对象带若干属性**"的内容，一律用表。散文会让读者无法横向比较——而横向比较正是这类内容存在的意义。

| 类型 | 典型并列项 | 建议表结构 |
|---|---|---|
| **统计口径／分类代码** | 国民经济行业分类、许可分类目录 | `\| 分类体系 \| 代码 \| 覆盖范围 \| 依据 \|` |
| **产品品类** | 行业主流品类群 | `\| 品类 \| 工艺 \| 产品形态 \| 渠道 \| 标准依据 \|` |
| **工艺层级** | 初加工／精深加工及其子类 | `\| 层级 \| 工艺 \| 典型产品 \| 附加值 \|` |
| **原料基地** | 各产区基地 | `\| 基地 \| 所在区域 \| 规模 \| 主栽品种 \| 依据 \|` |
| **区域格局** | 几大产业带／集群 | **见第六节** |
| **政策沿革** | 上位规划／一号文件／配套意见／财税／项目 | `\| 文件 \| 发布主体 \| 时间 \| 实施日期 \| 实际约束 \| 依据 \|` |
| **企业对比** | N 家代表企业 | `\| 企业 \| 代码 \| 总部 \| 核心品类 \| 关键财务 \| **毛利率** \| 市场定位 \|` |
| **出口品类** | 各品类量／额／均价／市场 | `\| 品类 \| 出口量 \| 同比 \| 出口额 \| 同比 \| 均价 \| 主要市场 \|` |
| **环节级利润** | 各环节毛利率 | `\| 环节 \| 毛利率 \| 收入占比 \| 来源 \| 样本量 \|` |
| **出清机制** | 逐环节五问 | `\| 环节 \| ①并购 \| ②标准 \| ③监管 \| ④渠道 \| ⑤规模 \| 命中 \| 档位 \|` |
| **机遇／挑战** | N 条机遇、N 条挑战 | `\| # \| 名称 \| 依据 \| 影响量级 \| 先行指标 \|` |
| **趋势主线** | N 条趋势 | `\| # \| 趋势 \| 依据 \| 投资含义 \| 反面证据 \|` |
| **风险清单** | N 个风险 | `\| 风险 \| 触发条件 \| 影响量级 \| 先行观测指标 \| 当前状态 \|` |
| **信息缺口** | 未取到的维度 | `\| # \| 缺失内容 \| 影响的章节 \| 已尝试检索 \| 建议取证方式 \|` |
| **投资含义** | **阶段 × 出清** | **见第四节矩阵** |
| **策略建议** | N 条策略 | **见下"策略例外条款"** |

### 5.1 例外：策略建议必须转成投资含义

**N 条策略若写的是"基地化／品牌化／数字化／集群协同"**，那是**企业管理建议**，不是投资分析。**必须补映射表**：

| 策略 | 对应可投环节 | 阶段 × 出清 | 所需条件 | **失效条件** |
|---|---|---|---|---|

**没有"失效条件"列的策略表，是建议不是分析**——读者无法判断什么情况下该放弃。

### 5.2 两条纪律

1. **单元格宽度看单元格，不看源文件行**。`| a | b | c |` 在源文件里可能 200+ 字符，但渲染后每格是独立窄列。**只有单元格本身 >100 字符才是问题**——那说明你把整段论证塞进了一格，应移到表下说明或正文。
2. **表下必须有配套**：① 用了代号／术语 → 表下紧跟说明；② "待核实／单源"标注 → 写在表下；③ **因果推演与概念解释仍用散文**——不要为用表而把推理压碎。

## 六、区域集群对照表（聚集区节的标准形态）

**问题**：这一段写成 N 篇小通告是本类报告最常见的结构病。症状是**各案例格式不统一**（有的给产值、有的给出口额、有的给产能、有的给品牌价值），**无法横向比较，也读不出结论**。

| 集群 | 核心区 | 规模指标 | 主导品类 | 国家级头衔 | 当前升级方向 | 代表企业 | 依据 |
|---|---|---|---|---|---|---|---|

**四条填写要求**

1. **规模指标必须统一口径**——全用产值，或全用加工能力，或**逐格标注**。**混用不同口径的"规模"列等于没有这一列**
2. **"升级方向"是关键列**——回答"这个集群正往哪走"，比"它有多大"更有判断价值
3. **"国家级头衔"单列**——国家现代农业产业园／优势特色产业集群／骨干冷链物流基地是**政策资源**，直接影响未来几年投入
4. **表下写 2–3 条横向结论**——**只给表不给结论，等于把分析工作推给读者**；N 个案例的正文压缩为表下说明，只保留该集群独有的、表里放不下的信息

## 七、"标题承诺 vs 内容交付"一致性核对

**最容易被忽略、也最损害可信度**：标题像投资分析、内容像产业盘点、建议像企业战略——**三者错位**。

### 7.1 三种报告定位（先确定，再核对）

| 定位 | 目标读者 | 结论部分形态 | 必备件 |
|---|---|---|---|
| **投资分析** | 投资人 | 可投性排序 + 所需条件 + **失效条件** | 阶段判定、环节级利润、出清机制、估值/周期位置 |
| **产业规划／招商** | 地方政府、园区 | 集群清单 + 扶持方向 + 招商建议 | 政策资源清单、产值/产能、企业图谱 |
| **行业研究／写文章** | 一般读者、媒体 | 趋势判断 + 关键变量 | 数据可靠性、来源透明、冲突并列 |

### 7.2 核对表

| # | 核对项 | 不通过的信号 |
|---|---|---|
| 1 | 标题的动词与报告实际做的事一致吗？ | 标题说"分析"，正文只"盘点" |
| 2 | 结论部分回答的是标题提出的问题吗？ | 标题问"能不能投"，结论答"企业该怎么办" |
| 3 | 若定位＝投资：有可投性排序与**失效条件**吗？ | 只有"机遇与挑战"清单 |
| 4 | 若定位＝投资：全文出现过"毛利率"吗？ | 企业数据**全是营收** |
| 5 | 若定位＝投资：有阶段判定与出清机制吗？ | 有数据无判断 |
| 6 | 若定位＝招商/规划：政策资源口径齐全吗？ | 只写产值不写政策头衔 |
| 7 | "案例"节可横向比较吗？ | N 篇格式不一的散文 |
| 8 | "策略建议"是企业该怎么做还是投哪一段？ | 全是管理动作，无失效条件 |

### 7.3 改造为投资版的优先顺序

| 顺序 | 动作 | 理由 |
|---|---|---|
| 1 | **已有素材能判的，先判** | 多数报告的阶段信号其实已齐（总量走平、价格历史低位、出清事件、结构性细分），只是没组织 |
| 2 | **用 F10 接口补环节级毛利率** | 一次接口调用即可，成本低、判断价值最高 |
| 3 | **逐环节做出清五问** | 素材常在报告里（破产/并购/标准/渠道/成本差异），只需组织 |
| 4 | **填投资含义矩阵** | 前三步的落点 |
| 5 | **重排结构 + 表格化** | 呈现层，最后做 |
| 6 | 若素材确实不足 → **声明局限或改标题** | 不要硬凑一个看起来像分析的结构 |

## 八、执行流程

```
① 定位          报告属于哪一类 → 决定要不要改造为投资版
② 骨架核对      九节逐节检查缺失；缺失的说明是"压缩"还是"漏"
③ 补阶段判定    按 A.1 判断顺序 → 五指标 → 渗透率校准 → 共线检查 → 冲突裁决 → 阶段标签
④ 补环节利润    用 F10 接口取分部毛利率（B.2）→ 按环节排列（B.3）→ 守三条读数纪律（B.4）
⑤ 补出清机制    逐环节五问（C.1）→ 定档 → 标碎片化陷阱（C.2）→ 与④并列输出（C.3）
⑥ 填投资矩阵    阶段 × 出清 → 12 格落点（第四节）
⑦ 呈现改造      按第五节表格化 + 第六节集群对照表 + 第七节一致性核对
⑧ 输出          投资版报告 + 改造说明（第九节）
```

**执行纪律**

- **能判的必须判**——不得只写"缺 XXX 维度"就收工；本技能内置判据，**要做出结论**
- **不能判的写"需另行取证"**——明确是缺数据，不是缺方法
- **不编数字**。取不到就写取不到，标"待核实／单源"
- **发现数据可疑只列出、不改动**，标"待核实"

### 9.2 交付物的两个文件（⚠️ 不要把工作日志混进报告）

| 文件 | 内容 | 给谁看 |
|---|---|---|
| **① 投资版报告** | 骨架见 9.1 + **《方法与数据来源说明》一节** | **读者**——只放结论与判断可信度所需的信息 |
| **② 改造记录**（单独文件） | 原报告定位判定、逐条改造动作、新增取数来源、待取证清单、数据疑点 | **审计／你自己**——工作底稿 |

**⚠️ 实测教训（必读）**：曾把"改造动作 1a/1b/2…"这类**工作日志**写进报告正文末尾，作为"改造说明"交付——**对读者是纯噪音**：读者要的是结论，不是版本差异日志。**报告正文只允许出现"影响判断可信度"的信息**，其余一律进《改造记录》。

**《方法与数据来源说明》一节只写四类内容**（缺一不可，多一不可）：

| 内容 | 为什么读者需要 |
|---|---|
| 数据来自哪里（原报告已有 / 哪个接口 / 报告期 / 样本量） | 判断结论可信度 |
| 口径纪律（哪些口径不混用、哪些是异常值） | 判断数字能不能横比 |
| 哪些维度**未取到**、结论因此**不成立** | 判断结论边界 |
| 数据疑点（只列不改） | 判断原始数据可靠性 |

**不属于这四类的，一律不进报告正文**——包括但不限于：改造了几步、删了哪节、原报告定位是什么、用了什么技能。

## 十、常见结构病与对症改法（速查）

| 病症 | 症状 | 改法 |
|---|---|---|
| **盘点冒充分析** | 信息全，但答不出"投哪一段" | 补三件套（第三～四节） |
| **并列项散文化** | N 个同类对象写成 N 段 | 按第五节清单改表 |
| **案例堆砌** | N 篇格式不一的通告 | 改集群对照表（第六节） |
| **策略错位** | 给"企业该怎么做"而非"投哪一段" | 加"对应可投环节 + 失效条件"两列 |
| **有数字无判断** | 罗列大量数据但无结论 | 每个数据块后加"因此…" |
| **口径混用** | 同一列混排产值/产能/出口额 | 统一口径或分列标注 |
| **标题错位** | 标题说分析、内容说现状 | 补三件套；素材不足则改标题/声明局限 |
| **趋势与数据脱节** | 趋势像愿景，前面数据没支撑 | 每条趋势回指前面的具体数据 |
| **只给阶段不给含义** | 判了成熟期但没说能不能投 | 必须填投资含义矩阵 |
| **出清判定按行业给** | 全行业一个档位 | 改逐环节判定 |

## 十一、边界（必须在输出中声明）

**本技能做什么**：改造报告结构、**做出投资判断**（阶段判定／环节级利润／出清机制／投资含义矩阵）、呈现改造。

**本技能不做什么**：

| 不做 | 原因 | 该用什么 |
|---|---|---|
| 大规模检索取证 | 本技能用已有内容 + F10 接口补数 | `industry-deep-research` |
| 给标的建议与估值 | 需公司层财报与估值模型 | 公司基本面分析 |
| 改动原文数据 | 只诊断与补判，不改写原始数值 | 由报告作者核实 |
| 编造缺失数字 | 取不到就标"需另行取证／待核实" | — |

**输出结尾必须声明**：

1. 本改造基于原报告已有内容 + **明确标注来源的新增取数**；
2. **未做核实的数据疑点仅列出**，不构成对其准确性的背书；
3. **标注"需另行取证"的维度**，其结论待数据补齐后方可成立。
