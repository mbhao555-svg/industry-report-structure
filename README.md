# industry-report-structure —— 行业报告结构改造器（投资版）

把"信息很全但读不出结论"的行业报告，改造成能回答 **"投哪一段"** 的投资分析报告。

## 它做什么

**两只手**：

| | 能力 | 产出 |
|---|---|---|
| **左手** | **投资判断**（判据完整内置，可独立完成） | 阶段判定／环节级利润分布／出清机制逐环节／**投资含义矩阵** |
| **右手** | **结构呈现** | 九节骨架诊断、并列项表格化、区域集群对照表、标题与内容一致性核对 |

## 它不做什么

| 不做 | 该用什么 |
|---|---|
| 大规模检索取证 | `industry-deep-research` |
| 给标的建议与估值 | 公司基本面分析 |
| 改动原文数据 | 由报告作者核实 |

## 安装

```bash
git clone https://github.com/mbhao555-svg/industry-report-structure
# 把 skills/industry-report-structure 复制到你的技能目录
```

DSH 用户：复制到 `~/.dsh/skills/`。

## 核心里程碑

| 版本 | 能力 |
|---|---|
| v1.0.0 | 只做结构诊断——**只指出缺什么** |
| **v2.1.0** | **内置完整投资判断判据——补出结论** |

## 首次实战

对《从"世界工厂"到"品牌主场"：中国果蔬加工行业深度分析报告（2026）》执行改造，产出 588 行投资分析报告：

- **阶段判定**：成熟期（五指标 5/5，置信度中）+ 四项冲突裁决记录
- **环节级利润**（F10 分部接口，报告期 2026-06-30）：国投中鲁苹果清汁 **14.23%**／欢乐家水果罐头 **23.97%**、椰子汁 **36.76%**／冠农果蔬 **16.06%**／宏辉水果 **11.61%**
- **出清机制**：逐 7 环节 —— 3 个"有出清机制"、2 个"出清缓慢"、1 个"碎片化陷阱"、1 个"未判"
- **投资结论**：鲜果流通／分销＝**碎片化陷阱，明确规避**
